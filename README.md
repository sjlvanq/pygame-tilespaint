# Pygame-Tilespaint
![screenshot](https://github.com/sjlvanq/pygame-tilespaint/raw/experimental/screenshot.png)
## Controls
```
DRAW: LEFT MOUSE BUTTON CLICK OR DRAG
ERASE: RIGHT MOUSE BUTTON CLICK OR DRAG
SCROLL: ARROW KEYS
PRINT ARRAY: ENTER
```
## Requirements
* Python3
* Pygame
